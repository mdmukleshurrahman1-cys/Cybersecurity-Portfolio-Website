SOC Analyst Portfolio — GitHub Pages

1. Create a GitHub repository named: YOURUSERNAME.github.io
2. Upload index.html, style.css, and script.js to the repository root.
3. In repository Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.
4. Wait a few minutes, then visit https://YOURUSERNAME.github.io/

Before publishing:
- Search and replace the LinkedIn and GitHub URLs with your own profile URLs.
- Replace your.email@example.com with your real public contact email (or remove the email link).
- Update the TryHackMe training and project descriptions to reflect only work you have actually completed.
- Do not publish credentials, flags, private data, or details from systems you are not authorized to test.

This is a static site; no Vercel account is needed.
